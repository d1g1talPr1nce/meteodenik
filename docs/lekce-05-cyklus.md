| Scénář | Můj předpoklad               | Skutečnost z Logcatu                                                                                                         | Proč se to liší                                                                           |
|---|------------------------------|------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| 1. Start aplikace z ikony | onCreate->onStart->onResume  | onCreate-> onStart-> onResume; savedInstranceState= null: true                                                               | Předpoklad odpovídá skutečnosti.                                                          |
| 2. Rotace displeje | Předpokládám, že se obrazovka překreslí a aktivita zůstane stejná. | onPause -> onStop -> onDestroy (isFinishing: false) -> onCreate (savedInstanceState == null: false) → onStart -> onResume    | Rotace mění konfiguraci, proto Android zničil původní instanci a vytvořil novou.          |
| 3. Stisk Home | onPause-> onStop             | onPause -> onStop                                                                                                            | Předpoklad odpovídá skutečnosti. Aktivita přešla do pozadí.                               |
| 4. Návrat do aplikace | onStart->onResume            | onRestart-> onStart-> onResume                                                                                               | Před onStart se zavolal také onRestart, protože se aktivita vracela ze zastaveného stavu. |
| 5. Stisk Zpět na MainActivity | Předpokládám ukončení aktivity. | onPause-> onStop                                                                                                             | Tlačítko zpět přesunulo úlohu do pozadí místo dokončení aktivity.                         |
